# FamilyHub

Planning a modular, self-hosted family server for 4–6 users, with a later public FOSS release.

The project integrates existing applications for movies, television, music, files, photos and shopping lists. Optional automatic downloads are included in the proposed architecture.

Read [the architecture review](ARCHITECTURE_REVIEW.md) for the service map, tradeoffs, storage and security boundaries, resource estimates, recovery design and decisions awaiting approval.

Status: architecture review. Application implementation has not started. The project license is not yet selected.
