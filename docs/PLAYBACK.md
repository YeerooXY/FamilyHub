# Sample playback

Status: **deployed and verified inside the Debian development VM.** Two services in `compose.playback.yaml` (project `familyhub-playback`): Jellyfin `12.4` and Navidrome `0.64.2`. Both run as UID/GID 2001 (reader), mount media read-only, and publish only on the guest's loopback: Jellyfin `127.0.0.1:8096`, Navidrome `127.0.0.1:4533`. Windows Chromium playback passed through workstation SSH forwards. Navidrome's forward at `http://127.0.0.1:14533/` was restored on 10 November and feeds the previously configured private Tailscale HTTPS endpoint for Android. Authentication and original audio delivery through that endpoint passed; actual phone playback remains pending. The SSH forward lasts only while its process runs. See [the verification record](PLAYBACK_VERIFICATION.md).

## Mounts

| Container path | Host path | Mode |
| --- | --- | --- |
| Jellyfin `/data/movies`, `/data/tv` | `/srv/familyhub/data/media/{movies,tv}` | read-only |
| Jellyfin `/config`, `/cache` | `appdata/jellyfin`, `appdata/jellyfin-cache` | read-write |
| Navidrome `/music` | `/srv/familyhub/data/media/music` | read-only |
| Navidrome `/data` | `appdata/navidrome` | read-write |

`appdata` stays `root:root 0700`. The three child directories are `2001:2001 0700`; bind mounts of those children work without the reader traversing the parent.

Hardening: `no-new-privileges`, all capabilities dropped, 10 MB × 3 log rotation, no privileged mode, host network, Docker socket or GPU. Both pinned images started successfully with these restrictions. Navidrome's insights collector is disabled (`ND_ENABLEINSIGHTSCOLLECTOR=false`). No credentials appear in Compose. Jellyfin's image has its own `/health` check; Navidrome has none here, so check `/ping` from the host with `curl`.

## Commands (Debian guest, as root, from the repository)

```
bash scripts/bootstrap-playback.sh
bash scripts/generate-samples.sh        # needs ffmpeg and ffprobe installed
cp -n .env.example .env
docker compose -f compose.playback.yaml --env-file .env up -d
docker compose -f compose.playback.yaml --env-file .env ps
docker compose -f compose.playback.yaml --env-file .env restart
docker compose -f compose.playback.yaml --env-file .env down      # keeps data and config
```

Both scripts stop before changing anything if a path component is a symlink or an existing object is unsafe. They preserve existing nonempty media. The generator removes only its temporary subtitle directory and a failed encode partial file. Rerunning is safe. The current development copy is installed under `/home/familyhub/playback`; copy updated scripts there before rerunning.

## First use

For this isolated sample deployment, run [the API checker](API_PLAYBACK_CHECK.md) once to provision separate administrator and regular test accounts and the Movie/TV libraries. Credentials stay in the guest root-only state directory. Do not reuse these development accounts for family production access. Navidrome reads `/music` automatically. No account password goes into Git.

## Samples

All files are synthetic and generated by `familyhub-writer`. Paths are under `/srv/familyhub/data/media/`.

| Path | Content | Limit |
| --- | --- | --- |
| `movies/FamilyHub Samples/Sample 1080p (2026)/Sample 1080p (2026).mkv` | 10 s, 1080p24 H.264 yuv420p; AAC tracks `eng` (440 Hz) and `hun` (660 Hz); embedded UTF-8 SRT `eng` and `hun` | Tests tags, track and subtitle switching. Tones carry no speech; Hungarian text tests UTF-8 rendering only. |
| `movies/FamilyHub Samples/Sample 4K HEVC (2026)/Sample 4K HEVC (2026).mkv` | 4 s, 2160p at 5 fps, HEVC yuv420p, AAC | A low-rate clip. It shows whether a client decodes or transcodes 4K HEVC. It says nothing about real 4K bitrate or HDR. |
| `music/FamilyHub Samples/Sample Artist/Sample CD 16-44.1/01…02` | Two 8 s FLAC tones, 16-bit 44.1 kHz | Tags: artist, album artist, album, title, track. |
| `music/FamilyHub Samples/Sample Artist/Sample HiRes 24-96/01…02` | Two 8 s FLAC tones, 24-bit 96 kHz | Generated natively at 96 kHz, not upsampled. Tones do not judge audio quality. Whether a client plays it bit-perfect is untested. |

A synthetic episode at `tv/FamilyHub Sample Series/Season 01/FamilyHub Sample Series - S01E01.mkv` hardlinks the 1080p movie fixture and is indexed as an episode. No MP3 or lossy fallback policy is approved; the format policy stays open.

## Checks (lead)

```
ffprobe -hide_banner "<file>"      # for each sample: codec, resolution, pix_fmt, audio and subtitle tags
curl -fsS http://127.0.0.1:8096/health
curl -fsS http://127.0.0.1:4533/ping
```

Linux and Windows Chromium decoded the 1080p sample with Hungarian subtitles and both FLAC albums. The 4K sample is indexed; its playback remains unverified. Pending: TV and phone clients, offline music, production GPU, LAN access, concurrent-load measurement, and independent backup.
